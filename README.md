# Calculadora de Rendimiento Compuesto

Aplicación web para proyectar el crecimiento de una cuenta de trading operación por operación.
Incluye conversión de resultados USD ↔ COP con tasa de referencia actualizada a diario.

## Publicar en GitHub Pages

1. Sube `index.html`, `LICENSE`, `README.md` y `.nojekyll` a un repositorio nuevo.
2. En **Settings → Pages**, elige la rama `main` y la carpeta `/ (root)`, y guarda.
3. En uno o dos minutos la app estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
